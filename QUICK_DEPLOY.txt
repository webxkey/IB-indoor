1️⃣  PREPARE YOUR SERVER
   ✓ Install PHP 8.2+ (with OpenSSL, PDO, PostgreSQL)
   ✓ Install PostgreSQL 12+
   ✓ Install Node.js 18+
   ✓ Install Composer

2️⃣  PULL CODE & INSTALL DEPENDENCIES
   $ git clone <your-repo>
   $ cd indoor-booking
   $ composer install --no-dev --optimize-autoloader
   $ npm install

3️⃣  CONFIGURE ENVIRONMENT
   $ cp .env.example .env
   $ nano .env  (or edit with your editor)
   
   ⚠️  IMPORTANT: Set these in .env:
       • DB_CONNECTION=pgsql
       • DB_HOST=localhost
       • DB_DATABASE=indoor_booking
       • DB_USERNAME=postgres
       • DB_PASSWORD=your_password
       • REVERB_HOST=your-server-ip
       • REVERB_PORT=8080

4️⃣  SETUP & BUILD
   $ php artisan key:generate
   $ createdb indoor_booking
   $ php artisan migrate --force
   $ npm run build
   $ php artisan config:clear

5️⃣  START SERVICES (TWO TERMINALS)
   
   Terminal 1 - Laravel Server:
   $ php artisan serve --host=0.0.0.0 --port=8000
   
   Terminal 2 - WebSocket Server:
   $ php artisan reverb:start --host=0.0.0.0 --port=8080

6️⃣  ACCESS & TEST
   • Open: http://your-server-ip:8000
   • Login with credentials
   • Create test booking: php complete-live-test.php
   • Watch dashboard for LIVE updates! ✨

KEY PORTS TO ALLOW:
  • Port 8000 - Laravel Application
  • Port 8080 - WebSocket (Reverb)
  • Port 5432 - PostgreSQL (optional, only if remote)

TROUBLESHOOTING:
  • Laravel won't start? → Check PHP version: php -v
  • WebSocket won't connect? → Check firewall: sudo ufw allow 8080
  • Database error? → Check PostgreSQL is running
  • Assets not loading? → Run: npm run build again

PRODUCTION NOTES:
  • Use Nginx/Apache instead of `php artisan serve`
  • Use Supervisor to keep services running
  • Set APP_DEBUG=false in .env
  • Use HTTPS for production
  • Configure proper database backups

FOR HELP:
  • Check logs: tail -f storage/logs/laravel.log
  • Browser console: F12 → Console tab
  • Verify services: netstat -tulpn | grep -E '8000|8080|5432'
