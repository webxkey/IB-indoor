⚡ MINIMUM REQUIREMENTS:

  - OpenSSL extension

🔑 CRITICAL CONFIGURATION (.env):

# Application
APP_NAME=Indoor Booking
APP_DEBUG=false (true only for debugging)
APP_KEY=<auto-generated>
APP_URL=http://your-server-ip:8000

# Database
DB_CONNECTION=pgsql
DB_HOST=localhost
DB_PORT=5432
DB_DATABASE=indoor_booking
DB_USERNAME=postgres
DB_PASSWORD=your_password

# WebSocket (Reverb)
REVERB_HOST=your-actual-server-ip (NOT localhost!)
REVERB_PORT=8080
REVERB_SCHEME=http (https for production)
BROADCAST_DRIVER=reverb

📊 DEPLOYMENT STEPS SUMMARY:

1. git clone/pull → Get latest code
2. composer install → Install PHP packages
3. npm install → Install JavaScript packages
4. .env setup → Configure database & services
5. php artisan key:generate → Generate encryption key
6. createdb → Create PostgreSQL database
7. php artisan migrate → Create database tables
8. npm run build → Compile frontend assets
9. php artisan serve → Start Laravel (port 8000)
10. php artisan reverb:start → Start WebSocket (port 8080)
11. Access: http://your-server-ip:8000 → Done! ✅

🚨 IF SOMETHING GOES WRONG:

1. Check SERVER_TROUBLESHOOTING.md
2. Verify services are running:
   $ netstat -tulpn | grep -E '8000|8080|5432'
3. Check Laravel logs:
   $ tail -f storage/logs/laravel.log
4. Check browser console (F12)
5. Run diagnostic:
   $ php artisan health
   $ php artisan tinker
