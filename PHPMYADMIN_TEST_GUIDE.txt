╔════════════════════════════════════════════════════════════════════════╗
║                   ⚡ PERFORMANCE NOTES                                 ║
╚════════════════════════════════════════════════════════════════════════╝

Polling Interval: 3 seconds (configurable)

To change polling speed:
- Edit: resources/views/livewire/staff/bookings-management.blade.php
- Find: setInterval(..., 3000)
- Change 3000 to:
  * 5000 = 5 seconds (slower, less server load)
  * 2000 = 2 seconds (faster, more responsive)
  * 1000 = 1 second (very fast, higher server load)

The system only polls when:
✅ Browser tab is visible
✅ User is on the booking page
❌ Stops polling when tab is hidden (saves resources)
